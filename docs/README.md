## Структурные правила проекта

Правила — **только про Rust-код**: `crates/*/src`, `crates/*/tests`,
`crates/*/benches`. Документация (`docs/**`, корневые `.md`) и `info/` вне
гейта: писать подробно там, где это документация, а не ограничивать объём
искусственно. Не учитываются также `Cargo.lock`, `.gitignore`, корень крейта
(в нём всегда лежат `Cargo.toml` + `build.rs`).

1. **Не больше 250 строк кода** в одном `.rs` файле. Пустые строки и
   полно-строчные комментарии (`//`, `///`, `//!`) не считаются —
   измеряется объём кода, а не документации.
2. **Не больше 4 `.rs`-файлов** в одной директории. Подпапки не ограничены:
   `src/` может содержать `lib.rs` и три модуля-директории, каждая из которых
   в свою очередь содержит не больше четырёх файлов.

`tests/` и `benches/` не исключены намеренно — иначе правило
«250 строк» обходится выносом кода в тесты.

Правило 2 — это не косметика: файл из тысячи строк означает, что в нём
смешаны разные причины к изменению (нарушение KISS/DRY/SOLID), а команда из
восьми файлов в одной папке — что модуль перестал быть модулем.

### Как проверяется

Правила гоняются **при компиляции**. Каждый крейт имеет `build.rs`:

```rust
fn main() {
    noxis_structure_check::check();
}
```

`noxis-structure-check` обходит деревья `src/`, `tests/` и `benches/` **этого
крейта** и **падает со стопкой ошибок**, если лимит нарушен. Поэтому
`cargo build` не соберёт нарушение — специально запускать проверку не нужно.
Деревья регистрируются через `cargo:rerun-if-changed`, чтобы гейт не
срабатывал на правки вне проверяемых путей.

Остальное, что не привязано к компиляции, собирается одним скриптом:

```sh
./scripts/check.sh   # structure → fmt → clippy -D warnings → test
```

### Что делать при нарушении

- файл разрослся → разрезать по одной ответственности на файл:
  `mod.rs` = публичный контракт модуля, соседние файлы — внутренности;
- папка переполнилась → завести подпапку и вынести подфункцию целиком,
  а не «чтобы влезло».

Каждый модуль получает `mod.rs` с `//!`-документацией — это точка входа,
читающаяся вместо пяти файлов.
